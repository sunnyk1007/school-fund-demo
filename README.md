# Maple Grove Elementary Community Fund Demo

A polished, mobile-first, static demo website for a school fundraising and volunteer platform.

## What is included

- Parent View
- School Administration View
- Annual fundraising tracker
- Dynamic event funding allocation logic
- Interactive event filters
- Donation modal with confirmation state
- Volunteer signup form with confirmation state
- Sponsor carousel
- Admin budget, event, volunteer, and sponsor management mockups
- Responsive mobile-first design

## Deploy on GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html` and `README.md` to the root of the repo.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/root**
5. Click **Save**.
6. GitHub will provide a public URL after the site deploys.

## Editing school data

Open `index.html` and find these JavaScript constants near the bottom of the file:

- `budget`
- `events`
- `sponsors`
- `volunteers`

Update those values with real school data when ready.
